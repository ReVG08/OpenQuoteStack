# Roadmap

## Available

Portable definitions, exact pricing, conditions, arithmetic formulas, authentication,
organization permissions, immutable revisions, saved estimates and a moving demo.

## Next

- A visual estimator builder and field/rule authoring flows.
- Branded public estimator rendering, publication and embedding.
- Lead capture with retention and export policies.
- Organization settings, invitations and membership management.
- Account verification and password recovery delivery.
- Expanded template examples and localization coverage.

## Later

- Versioned REST API, scoped API keys and a network SDK.
- Durable webhook delivery and integration events.
- Analytics and estimator conversion reporting.
- PDF documents, custom domains and deployment hardening.
- Accessibility and compatibility verification across supported browsers.

These are planned areas, not release commitments. Pricing semantics and portable
schema compatibility need explicit versioning as the format evolves.
